Physics-constrained neural network: a negative result

Nyando Flood AI, Phase D

Case studiesResearchWritingExperienceSkillsAboutCV

Last updated: 18 Nov 2026

Result

The physics-constrained network was not promoted. On the mappable frame it trailed the registered gradient-boosting model by −0.0098 mean per-event AUC (97.5% interval −0.0204 to −0.0005; 4 wins, 13 losses, 6 ties over 23 events). It also broke the physical direction rules on many rows, so it could not pass the protocol's export gate for a served model.

Question

Flood susceptibility should move in known directions: lower ground, gentler slope, more rain and closer water should never lower the score. Gradient boosting can enforce this exactly with monotonic constraints. Can a neural network with a soft penalty for wrong directions match it?

Design, fixed before any score

  • Comparator: the registered monotonic gradient-boosting model (hgb:con).
  • Network: 14 inputs, two hidden layers, tanh, Adam, 100 epochs, seed 42, on CPU. Grid of 6 points: hidden sizes (32, 16) or (64, 32), penalty weight 0, 1 or 10.
  • The penalty acts on four features: elevation, slope, 3-day rainfall and distance to water.
  • Nested selection with event-grouped inner folds; 35 leave-one-event-out outer folds, scored on the 23 events that contain both floods and non-floods.
  • Export gate X3, set before training: a served network must break the direction rules on zero of 200 real rows checked.
  • Statistics: paired per-event bootstrap, 10,000 resamples, 97.5% interval.

What it shows

  • A soft penalty reduced some violations but did not remove them. Only a hard constraint guaranteed the physical direction.
  • The network still beat elevation alone (+0.0358, 97.5% interval +0.0046 to +0.0721), so it learned something real. It was simply not better than the simpler constrained model.
  • Once the check showed the selected network could not pass X3, an amendment (r4) ended Phase D early. The sealed second block of 26 events stays unopened for a future challenger.

Limits

One network family and one small grid were tested. The result does not say neural networks cannot work here, only that this design did not beat the registered model under the rules set in advance. It is a soft-penalty network, not a physics-informed neural network solving equations.
