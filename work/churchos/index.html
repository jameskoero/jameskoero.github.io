ChurchOS

Multi-tenant church management software

Status: Phase 1 live; later phases in development  |  Last updated: 15 Nov 2026

Problem

Churches need one system for members, giving and records, with each church's data kept separate. ChurchOS is a multi-tenant product: one platform, many separate churches.

Architecture

  1. Installable web app (PWA) on Vercel
  2. API on Render
  3. PostgreSQL database on Neon

Implementation, Phase 1 (from the repository README)

  • JWT authentication.
  • Role-based access control with five roles.
  • A finance audit log.
  • M-Pesa and Flutterwave payment integration.

Design decisions

  • Each church connects its own M-Pesa, so giving goes straight to the church and not through the platform.
  • Each church picks its denomination, and the product follows that denomination's structure.

Results and limitations
