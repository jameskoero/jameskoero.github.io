AfriSalaries

Salary-band classifier across 8 African markets

Status: Deployed (May 2026)  |  Last updated: 15 Nov 2026

Problem

Predict a salary band, rather than an exact figure, for tech roles across 8 African markets, from the text of job descriptions.

Architecture

Implementation

  • XGBoost classifier on TF-IDF features, explained with SHAP.
  • Two regression designs for exact salary were rejected on validation grounds (R-squared 0.34, then 0.38). I documented both as architectural decisions and moved to bands.

Evaluation

Band accuracy: 59.5%.

Production engineering

An API on Render serves the model to a React frontend on Vercel. Model files are backed up outside the repository.

My contribution

I built the data pipeline, models, API and frontend, and deployed them as the sole developer.

Results and limitations

  • 59.5% band accuracy is a moderate result, and I report it as such.
  • 1,526 records across 8 markets is a small dataset, so estimates are indicative only.

Reproducibility and links

The live app is the working demonstration. Source and setup steps are in the repository README.
