AfriSalaries

Salary-band classifier across 8 African countries

Status: Deployed (May 2026)  |  Last updated: 15 Nov 2026

Problem

Estimate a salary band, rather than an exact figure, from 1,526 real records covering 8 African countries.

Architecture

  1. 1,526 real records, 8 countries
  2. XGBoost band classifier
  3. API hosted on Render
  4. Frontend hosted on Vercel

Implementation

  • XGBoost classifier that predicts a salary band.
  • Two earlier regression attempts to predict exact salary failed (R-squared 0.34, then 0.38). I documented both as architectural decisions and moved to bands.

Evaluation

Band accuracy: 59.5%.

Production engineering

The model is served by an API on Render and used by a web frontend on Vercel. Model files are backed up outside the repository.

My contribution

I built the data pipeline, models, API and frontend, and deployed them as the sole developer.

Results and limitations

  • 59.5% band accuracy is a moderate result, and I report it as such.
  • 1,526 records across 8 countries is a small dataset, so estimates are indicative only.
