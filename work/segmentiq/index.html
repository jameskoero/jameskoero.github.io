SegmentIQ

K-Means customer segmentation with batch CSV upload

Status: Deployed (live app)  |  Last updated: 15 Nov 2026

Problem

Group customers into segments from three inputs: age, annual income and spending score, and show a tailored business strategy for each segment.

Requirements

  • Assign a customer to one of 5 segments.
  • Accept a CSV file and segment many customers at once.
  • Show a business strategy for the assigned segment.

Architecture

Implementation

  • K-Means clustering into 5 segments.
  • Cold-start fix: a retrying API hook and a warm-up provider, so the page copes while the backend wakes up.

Evaluation

The repository README says 5 segments were chosen with the elbow method (inertia for K from 1 to 10) and reports segment sizes and average profiles. No silhouette score or other cluster-quality measure is published.

My contribution

I built the model, API and frontend, and deployed them as the sole developer.

Results and limitations

  • Clustering is unsupervised: segments describe patterns in the data, they are not verified customer types.
  • The repository README names the Mall Customers dataset (200 rows). The repository is archived and its README still lists two inputs, while the live app takes three.
  • The backend may take time to respond after it has been idle.

What I would do next

  • Publish a cluster-quality measure, such as silhouette score, beside the elbow plot.
  • Update the repository README to describe the live app and its three inputs.

Reproducibility and links

The live app accepts a CSV file for batch segmentation. The backend may take time to answer after it has been idle. Source and setup steps are in the repository README.
