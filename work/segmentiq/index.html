SegmentIQ

K-Means customer segmentation with batch CSV upload

Status: Deployed  |  Last updated: 15 Nov 2026

Problem

Group customers into segments from three inputs: age, income and spending score.

Requirements

  • Assign a customer to one of 5 segments.
  • Accept a CSV file and segment many customers at once.

Architecture

  1. React frontend on Vercel
  2. FastAPI backend on Render
  3. K-Means model with 5 segments

Implementation

  • K-Means clustering into 5 segments.
  • Cold-start fix: a retrying API hook and a warm-up provider, so the page copes while the backend wakes up.

Evaluation

No validation metric for the clusters is published on this page yet.

My contribution

I built the model, API and frontend, and deployed them as the sole developer.

Results and limitations

  • Clustering is unsupervised: segments describe patterns in the data, they are not verified customer types.
  • The backend may take time to respond after it has been idle.
