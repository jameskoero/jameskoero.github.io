How I work

Four habits that show up in every project above.

Protocol before scoring

Decision rules go into a written protocol before any model is scored. In Nyando V2, the sealed events were scored once.

Report what didn’t hold

My Nyando champion’s edge did not replicate on sealed events, a neural network trailed, and my own first version was retracted. All of it is on the record.

Serve only what you verified

The API checks the model’s SHA-256 before loading it, and production installs are hash-locked: 31 packages, 483 hashes.

Build for the connection you have

I build and ship from an Android phone over mobile data, so pipelines are lean, reproducible and tested in CI.
